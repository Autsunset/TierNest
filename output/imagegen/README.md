# TierNest launcher artwork

Generated on 2026-09-20 through the user-authorized Image API with model
`gpt-image-2.5`, high quality. The exact prompt is in `tiernest-icon-prompt.txt`.
`tiernest-icon.png` preserves the returned 1254×1254 RGBA image without metadata.
No API credentials or service URLs are included.

The Android foreground is a derived 1024×1024 transparent canvas. Alpha values
below 9 are cleared to remove stray transparent-edge noise; the remaining alpha
is rescaled, and the visible artwork is fitted to a centered 600×600 safe area.
The adaptive icon supplies a separate midnight background and Android's own mask.
The Quick Settings and notification symbols use an independent transparent vector
so system tinting preserves the network mark instead of producing a solid square.
