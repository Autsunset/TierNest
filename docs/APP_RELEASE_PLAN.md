# TierNest App 正式版优化与验收计划

目标：将 `0.2.0-alpha10` 收敛为可维护、可覆盖升级、可验证的 `0.2.0`。
先冻结功能并交付候选版，满足本页验收条件后再发布正式版。
本计划面向独立 Android App；已停止发布的 Root 模块仅保留迁移兼容。

## 执行顺序

1. 审查并建立问题清单，冻结新功能；不通过盲目升级依赖或改版本号代替优化。
2. 修复可复现的 P0/P1 问题，为失败、并发和兼容场景补充必要回归。
3. 固定签名与产物检查流程，生成可审阅的候选 APK、源码包和校验文件。
4. 运行自动化与可用设备测试，核对升级前后配置、网络状态和退出后的资源。
5. 使用同一候选包进行实体手机验收；发现问题则修复并重测受影响场景。
6. 仅在无未关闭的 P0/P1 问题、必需验收通过后去掉候选版标记并发布。

## 验收矩阵

| 场景 | 验收内容 | 证据要求 |
| --- | --- | --- |
| VPN 基本连接 | 建立虚拟接口、真实对端通信、普通网络不被接管、授权撤销后停止 | 实际流量与状态记录 |
| Root 基本连接 | 授权、核心启动、路由同步、停止后核心/规则清理 | 实体 arm64 Root 设备 |
| 热点共享 | 客户端访问组网、正常上网、禁止新建反向连接、关闭/换网段后清理 | 隔离网络回归 + 实体热点 |
| 异常与竞争 | 超时、断网、连续启停、模式切换、配置保存期间手动停止 | 故障注入与实际操作 |
| 升级与数据 | 原始 TOML、家庭/热点偏好、手动停止、备份完整保留 | 覆盖安装前后字节/内容核对 |
| Android 兼容 | Android 8/9 权限与存储；较新系统通知/前台服务/文件选择器 | 分版本实测，注明未覆盖范围 |
| 长时间运行 | 前后台与锁屏切换、流量连续性、内存/FD/线程/进程是否持续增长 | 同一版本连续观察，保留时间与结果 |
| 发布 | 包名、版本码、签名、非调试标志、对齐、隐私、R8 映射、下载校验 | 自动检查与发布后摘要 |

实体网络和待机验证不能用模拟器或离线测试替代。不能执行的项目必须保留为未验收，
不得仅凭“编译通过”或一次短连接标为完成。

## 固定约束

- 保留 `com.tiernest.app` 与现有签名的升级兼容性；不要求用户卸载丢失配置。
- 原始 TOML、明确的运行偏好和手动停止具有最高优先级。
- 不引入无限重试、周期唤醒、待机轮询或默认开启的热点共享。
- 配置、密钥、截图、原始诊断、运行状态与签名私钥不进入仓库和公开产物。
- 发布记录说明验证环境、使用的包及仍存在的限制。

## 已完成的优化与证据

- **签名和 CI**：独立发布密钥库保持已发布证书身份，CI 独立包名与密钥；实际 APK
  身份/签名/非调试/双 ABI/16 KiB/Root 清单核验通过。缺失发布密钥和 CI 包冒充发布包
  的负向检查均被拒绝。
- **配置与迁移**：Android 8 的直接备份及保存触发备份均能按需授权；拒绝后配置不变，
  允许后继续原操作，旧配置备份逐字节核对。迁移提交顺序、写前/写后失败、回滚失败与
  停止优先均有回归。原始文本的注释/CRLF、最新的非导入偏好保留。
- **用户流程**：缺少 DocumentsUI 时能显示本地提示且进程不退出；外部链接增加保护，
  家庭复验错误可见；热点能力、事件检测和备份保留文案已纠正。
- **Root 会话**：只读校验/备份的完整操作失败保留健康连接；无效草稿先本地拒绝。
  临时会话、通信超时、取消与清理异常的证据保留均有回归。
- **热点**：25 项状态回归及 128 目标真实 iptables/路由隔离测试通过；同环境单次
  清理测量约 1.91 秒 → 1.00 秒，普通上网、入站限制、幂等和精确清理不变。
- **VPN**：Android 8 与 Android 15 实际通过加密组网访问合成对端的 HTTP 子网代理。
  排除无效虚拟地址，避免 MTU 单侧截断；冗余路由去除不扩大覆盖。覆盖内节点离开不重建
  接口，新子网加入时可完成接口切换并继续通信。
- **历史迁移**：通用模块 14 个升级/失败场景通过，包括三个旧标签、首次安装和旧模块迁移。

## 尚未完成的正式版门槛

1. 实体 arm64 手机/平板的 Root 授权、热点、切换 Wi-Fi/移动网络、Clash 共存、锁屏和重启。
2. 同一候选包的实体设备长时间运行与待机；模拟器有持续测试流量，不能代表真实功耗。
3. 首轮 30 分钟模拟器观察里有 3 次采样异常，应用 PID 未变且资源未持续增长。
   旧采样器未记录异常阶段/已接收数据，尚不能归因于应用断线；100 次随后请求均成功。
   工具已补充连接/空闲/EOF 截止与阶段记录，继续复测并保留原异常统计。

这些项目保持未验收，因此本轮交付 `0.2.0-rc01`，不会直接改成正式版。

  通过，另有 14 项历史模块迁移场景通过。实体设备条目继续保持未验收。
